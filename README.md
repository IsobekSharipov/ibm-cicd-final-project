# IBM CI/CD Final Project

**Project Name:** IBM CI/CD Final Project — GitHub Actions, Tekton, and OpenShift

This repository contains the source code and CI/CD configuration for the IBM final project. The project demonstrates automated code quality checks, unit tests, container build and deployment preparation using GitHub Actions and OpenShift Pipelines (Tekton).

## Project Overview

The goal is to implement a continuous integration and continuous delivery (CI/CD) pipeline for a sample application. The implementation will cover:

- Source code hosted in a public GitHub repository.
- Automated linting and unit testing with GitHub Actions.
- Tekton tasks for workspace cleanup and testing.
- OpenShift Pipelines with persistent workspace storage (PVC).
- Pipeline execution and application log verification.
